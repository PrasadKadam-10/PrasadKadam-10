## Featured Projects

### 🧩 HireIQ — Multi-Agent AI Hiring System
A production-style recruitment platform that automates candidate evaluation through a coordinated graph of specialized agents.

- **9 specialized agents** — resume parsing, semantic matching, evaluation, ranking, and reporting — orchestrated with **LangGraph**
- **Resume Intelligence** — parses PDFs into structured, recruiter-ready candidate summaries
- **Semantic Skills Matching** — embedding-based vector search instead of brittle keyword matching
- **Web Intelligence** — live GitHub, LinkedIn, and portfolio enrichment via Exa AI
- **Recruiter Dashboard** — Next.js frontend for job creation, candidate tracking, and hiring insights

`LangGraph` `Python` `Next.js` `MongoDB`

---

### 🚄 OnTrack — AI Train Induction Planning (Smart India Hackathon 2025)
Selected among 50 teams from college for the SIH 2025 internal round. Built an AI-driven scheduling system for train induction planning for **Kochi Metro Rail Limited (KMRL)**, as part of a 5-member team.

`AI Scheduling` `Optimization` `Team Project`

---

### 📊 Spandan — Live Classroom Polling Platform
An internship project delivering real-time interactive polling built to handle 300–400 concurrent students in a single session.

- Real-time updates via **Socket.IO**, with **Redis** for scaling concurrent connections
- **LLM-powered question generation** (OpenAI / Anthropic / Google / MiniMax)
- Full-stack build across React/Vite, Node.js/Express, and MongoDB

`React` `Node.js` `Socket.IO` `Redis` `MongoDB`
