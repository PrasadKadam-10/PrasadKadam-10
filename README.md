## Featured Project — HireIQ

**A multi-agent AI hiring system** that automates candidate evaluation through a coordinated
graph of specialized agents — resume parsing, semantic skills matching, web intelligence
enrichment, and reasoning-based AI evaluation — orchestrated with LangGraph.

- 🕸️ **Multi-Agent Workflow** — 9 specialized agents (parsing, matching, evaluation, ranking, reporting) coordinated as one reasoning graph
- 📄 **Resume Intelligence** — PDF parsing into structured, recruiter-ready candidate summaries
- 🔍 **Semantic Skills Matching** — embedding-based vector search instead of keyword matching
- 🌐 **Web Intelligence** — live GitHub, LinkedIn, and portfolio enrichment via Exa AI
- 📊 **Recruiter Dashboard** — a Next.js frontend for job creation, candidate tracking, and hiring insights
